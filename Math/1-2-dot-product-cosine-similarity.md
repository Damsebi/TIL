## 2. 나만의 정리

내적은 두 벡터에서 같은 위치의 성분끼리 곱한 뒤 모두 더한 값이다.

내적의 결과는 스칼라로 나오며, 이 하나의 숫자를 이용해 벡터 사이의 관계를 비교할 수 있다.

다만 내적은 벡터의 크기에도 영향을 받기 때문에, 값이 크다고 해서 두 벡터의 성향이나 의미가 반드시 비슷하다고 보기는 어렵다.

그래서 방향의 유사도를 비교할 때는 코사인 유사도를 사용한다.

코사인 유사도는 두 벡터가 같은 방향인지, 수직인지, 반대 방향인지를 확인할 수 있다.

코사인 유사도를 구하려면 두 벡터의 내적을 각 벡터 크기의 곱으로 나눈다.

$$
\text{cosine similarity} =
\frac{
\mathbf{a}\cdot\mathbf{b}
}{
\|\mathbf{a}\|
\|\mathbf{b}\|
}
$$

아직 이 공식이 왜 이런 형태가 되는지는 완전히 이해하지 못했지만, 내적의 기하학적 공식에서 $\cos\theta$를 구하도록 식을 정리한 결과라고 이해했다.

임베딩은 텍스트나 이미지를 숫자 벡터로 변환하는 과정이다.

텍스트나 이미지의 유사도를 계산하려면 먼저 비교할 대상을 벡터로 표현해야 하므로 임베딩이 먼저 필요하다.

코사인 유사도가 0이면 두 벡터가 수직이라는 뜻이다. 임베딩에서는 의미적으로 관련이 적다고 해석할 수 있지만 항상 절대적으로 무관하다는 뜻은 아니다.

`a @ b`는 내적을 수학적으로 표현하는 기호처럼 보였지만, Python과 NumPy에서는 실제 연산자로 동작한다는 점이 인상적이었다.

내적이 클수록 전체 구매량이나 구매력 같은 크기는 크게 반영될 수 있지만, 상품별 단위 차이나 전체 구매량의 영향을 받기 때문에 구매 성향이나 선호도를 비교하기는 어려울 수 있다.

자기 자신과의 코사인 유사도는 1이므로 가장 높은 값이 나온다. 반면 자기 자신과의 내적은 자신의 노름을 제곱한 값이지만, 크기가 더 큰 다른 벡터와의 내적보다 항상 크다고 할 수는 없다.

코사인 유사도로 비슷한 다른 고객을 찾을 때는 자기 자신을 결과에서 제외해야 한다.

`np.dot()`은 직접 성분별 곱셈과 합을 작성하는 것보다 내적을 간단하게 표현할 수 있는 기능이다.

```python
def cosine(a, b):
    return np.dot(a, b) / (
        np.linalg.norm(a)
        * np.linalg.norm(b)
    )
```

코사인 유사도는 위처럼 직접 구현할 수도 있지만, 라이브러리의 `cosine_similarity()` 기능을 사용할 수도 있다.

## 4. 학습하며 겪었던 문제점과 해결 과정

### 코사인 유사도 공식을 이해하기 어려웠다

코사인 유사도를 구할 때 내적을 두 벡터 노름의 곱으로 나누는 이유가 바로 이해되지 않았다.

내적의 기하학적 정의는 다음과 같다.

$$
\mathbf{a}\cdot\mathbf{b} =
\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta
$$

이 식의 양변을 $\|\mathbf{a}\|\|\mathbf{b}\|$로 나누면 다음 식이 된다.

$$
\cos\theta =
\frac{
\mathbf{a}\cdot\mathbf{b}
}{
\|\mathbf{a}\|
\|\mathbf{b}\|
}
$$

따라서 코사인 유사도 공식은 별도의 새로운 공식을 외우는 것이라기보다, 내적의 기하학적 식에서 $\cos\theta$를 구하도록 정리한 결과이다.

---

### 내적이 크면 유사도가 높은 것인지 헷갈렸다

내적은 벡터의 방향뿐 아니라 크기에도 영향을 받는다.

구매량이 많은 고객은 여러 성분의 값이 크기 때문에 다른 고객과의 내적도 크게 나올 수 있다.

따라서 절대적인 구매 규모를 비교할 때는 내적이 의미가 있을 수 있지만, 구매 성향이나 방향을 비교할 때는 코사인 유사도가 더 적절할 수 있다.

---

### 자기 자신과의 코사인 유사도가 가장 높게 나왔다

0이 아닌 벡터와 자기 자신의 코사인 유사도는 1이다. 이는 코사인 유사도의 최댓값이므로 자기 자신이 가장 높은 값으로 나온다.

다른 고객 중 가장 비슷한 고객을 찾으려면 자기 자신의 행을 제거하거나 제외한 뒤 정렬해야 한다. 내적은 벡터 크기의 영향을 받기 때문에 자기 자신과의 값이 항상 가장 크다고 보장할 수 없다.

---

### `sort_values(ascending=False)`의 의미

`sort_values()`는 Pandas의 `Series` 또는 `DataFrame` 값을 기준으로 정렬하는 기능이다.

```python
similarities.sort_values(ascending=False)
```

`ascending=False`는 값을 큰 값부터 작은 값 순서로 정렬한다는 뜻이다.

- `ascending=True`: 오름차순
- `ascending=False`: 내림차순

코사인 유사도를 내림차순으로 정렬하면 가장 유사한 대상부터 확인할 수 있다.

자기 자신을 제외하고 가장 유사한 고객을 찾는 예시는 다음과 같다.

```python
sorted_similarities = similarities.drop(
    index=target_index
).sort_values(
    ascending=False
)

print(sorted_similarities)
```

### `cosine_similarity()` 기능

직접 만든 함수 외에도 scikit-learn에서 코사인 유사도를 계산할 수 있다.

```python
from sklearn.metrics.pairwise import (
    cosine_similarity
)

result = cosine_similarity(matrix)
```

행렬을 전달하면 각 행 벡터 사이의 코사인 유사도를 계산한 행렬을 반환한다.

## 정리

- 내적은 같은 위치의 성분끼리 곱한 뒤 모두 더한 스칼라 값이다.
- `np.dot(a, b)`와 `a @ b`로 벡터의 내적을 계산할 수 있다.
- 내적은 벡터의 크기와 방향에 모두 영향을 받는다.
- 코사인 유사도는 내적을 두 벡터 노름의 곱으로 나눈 값이다.
- 코사인 유사도는 벡터의 크기보다 방향의 유사성을 비교한다.
- 임베딩은 텍스트나 이미지를 숫자 벡터로 변환하는 과정이다.
- 임베딩된 벡터의 코사인 유사도를 이용해 검색과 추천을 구현할 수 있다.
- 유사도 결과를 정렬할 때 `sort_values(ascending=False)`를 사용하면 큰 값부터 확인할 수 있다.
- 유사한 다른 대상을 찾을 때는 자기 자신을 비교 대상에서 제외해야 한다.
