## 2. 나만의 정리

처음에는 가입 가능성 점수를 가입한 사람과의 내적이나 코사인 유사도로 계산하는 것인지 궁금했다.

이번 실습에서 계산한 방식은 유사도를 구하는 것이 아니라, 고객의 특성값에 가중치를 곱해 가중합을 만들고 편향을 더해 출력 점수를 만드는 방식이었다.

$$
Y = XW + b
$$

다만 실습에서 `np.random.randn()`으로 만든 `W`와 `b`는 행렬 연산과 Shape를 확인하기 위한 임의의 값이다.

실제 가입 가능성을 판단하려면 과거 고객 데이터와 실제 가입 여부를 이용해 학습된 가중치와 편향이 필요하다.

`X.shape == (8, 5)`라는 것은 고객이 8명이고 각 고객에게 특성이 5개 있다는 뜻으로 이해했다.

`X`는 고객 한 명의 데이터가 아니라 여러 고객의 데이터를 모은 전체 데이터 행렬이다.

`np.random.randn()`은 정규분포를 따르는 임의의 숫자를 생성하는 기능이다.

가중치는 각 특성을 출력 점수에 얼마나 반영할지를 나타낸다.

처음에는 내적이 클수록 가중치의 중요도가 높다는 뜻으로 생각했지만, 내적은 데이터와 가중치를 함께 계산한 결과이다.

특성 자체의 반영 방향과 크기는 가중치로 확인할 수 있다.

다만 가중치의 절댓값만으로 특성 중요도를 비교하려면 각 특성의 단위가 비슷해야 한다.

예를 들어 자산 금액과 보유 주택 수처럼 단위와 범위가 크게 다른 값을 그대로 비교하면 가중치만으로 중요도를 판단하기 어렵다.

이번 코드에서 `StandardScaler`를 사용한 이유도 특성들의 단위를 맞춰 계산과 비교를 쉽게 하기 위한 것으로 이해했다.

편향은 모든 특성의 가중합을 계산한 뒤 마지막에 더하는 기본 점수이다.

처음에는 모든 고객에게 같은 값을 더하면 고객 간 비교 결과는 달라지지 않는데 왜 필요한지 궁금했다.

편향은 모델의 판단 기준을 원점에 고정하지 않기 위해 필요하다고 이해했다.

모든 특성이 평균 수준인 고객이라도 현실에서 가입 가능성이 정확히 중간이라고 볼 수는 없다.

모델은 실제 정답을 학습하면서 기본적인 출력 수준에 맞도록 편향을 조정한다.

출력이 3개라면 편향도 3개이며, 각 출력 점수는 자기 편향값을 하나씩 가진다.

예를 들어 카드 가입, 대출 가입, 통장 개설 점수를 동시에 출력한다면 각 출력에 대응하는 편향값이 필요하다.

반복문 실습에서는 무작위 데이터와 실제 데이터를 비교하는 것이 아니었다.

```python
X[i] @ W + b
```

를 이용해 고객 한 명씩 계산한 결과와,

```python
X @ W + b
```

를 이용해 모든 고객을 한 번에 계산한 결과가 같은지를 확인하는 실습이었다.

`X.shape[0]`은 고객 수인 8이므로 반복문은 각 열이 아니라 각 고객 행을 순서대로 처리한다.

전치행렬은 행과 열을 바꾸는 연산이다.

데이터 행렬을 전치하면 고객 한 명의 특성을 행 단위로 보는 대신, 하나의 특성에 대한 여러 고객의 값을 행 단위로 볼 수 있다.

또한 행렬곱이 가능하도록 Shape를 맞추는 과정에서도 사용할 수 있다.

행렬곱을 전치하면 다음처럼 순서도 반대로 바뀐다.

$$
(XW)^T = W^T X^T
$$

`X.T @ W.T`가 아니라 `W.T @ X.T`가 되는 이유는 행렬곱이 앞 행렬의 행과 뒤 행렬의 열을 내적하는 연산이기 때문이다.

## 4. 학습하며 겪었던 문제점과 해결 과정

### 출력 점수는 어떻게 계산되는가?

처음에는 고객의 가입 가능성 점수를 기존 가입 고객과의 유사도로 계산하는 것인지 궁금했다.

이번 강의에서 다룬 완전연결층은 고객의 입력 특성에 가중치를 적용하고 편향을 더해 출력 점수를 계산한다.

```python
Y = X @ W + b
```

다만 임의로 만든 `W`와 `b`의 출력은 실제 가입 확률이 아니다.

실제 판단에 사용할 값은 학습 과정에서 결정된 가중치와 편향을 사용해야 한다.

---

### 가중치가 크면 무조건 중요한 특성인가?

가중치의 크기는 해당 특성이 출력에 미치는 영향을 해석하는 단서가 될 수 있다.

하지만 특성마다 단위와 값의 범위가 다르면 가중치 크기만 직접 비교하기 어렵다.

따라서 특성 중요도를 가중치로 비교하려면 입력 특성의 스케일과 모델 구조도 함께 고려해야 한다.

---

### 편향은 왜 필요한가?

편향이 없다면 입력 특성이 모두 0일 때 출력도 항상 0이 된다.

편향을 사용하면 입력이 0인 경우에도 모델이 데이터에서 학습한 기본 출력값을 가질 수 있다.

따라서 편향은 모델의 기준점을 원점에서 이동시키는 역할을 한다.

---

### 반복문과 행렬곱은 무엇을 비교하는가?

반복문은 각 고객을 한 명씩 계산한다.

```python
X[i] @ W + b
```

행렬곱은 같은 계산을 모든 고객에게 한 번에 수행한다.

```python
X @ W + b
```

`np.allclose()`로 두 결과를 비교해 배치 행렬곱이 반복문 계산과 같은 결과를 만든다는 것을 확인했다.

---

### Shape 오류는 왜 발생하는가?

`X.shape`이 `(8, 5)`라면 `X`의 열 개수는 5이다.

따라서 뒤에 곱하는 `W`의 행 개수도 5여야 한다.

```text
X:       (8, 5)
W_wrong: (4, 3)
```

위 Shape는 가운데 숫자 `5`와 `4`가 다르기 때문에 행렬곱을 계산할 수 없다.

올바른 가중치 Shape는 다음과 같다.

```text
W_fixed: (5, 3)
결과:    (8, 3)
```

행렬곱 가능 조건은 다음 한 문장으로 정리할 수 있다.

> 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 한다.

---

### 전치하면 왜 곱의 순서가 바뀌는가?

`X`와 `W`의 Shape가 다음과 같다고 가정한다.

```text
X: (8, 5)
W: (5, 3)
```

원래 곱의 결과는 다음과 같다.

```text
X @ W: (8, 3)
```

이를 전치하면 `(3, 8)`이 된다.

각 행렬을 따로 전치하면 다음과 같다.

```text
X.T: (5, 8)
W.T: (3, 5)
```

원래 순서를 유지한 `X.T @ W.T`는 가운데 차원인 8과 3이 맞지 않아 계산할 수 없다.

순서를 반대로 한 `W.T @ X.T`는 다음처럼 계산할 수 있다.

```text
(3, 5) @ (5, 8) → (3, 8)
```

따라서 다음 성질이 성립한다.

$$
(XW)^T = W^T X^T
$$

---

## 정리

- 행렬의 덧셈은 같은 위치의 원소끼리 계산하며 Shape가 같아야 한다.
- 행렬곱은 앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 한다.
- 데이터 행렬 `X`에서는 행이 샘플, 열이 특성을 나타낸다.
- 완전연결층은 `Y = XW + b`로 표현할 수 있다.
- `W`는 입력 특성을 출력에 반영하는 가중치 행렬이다.
- `b`는 출력별 기본값을 조정하는 편향 벡터이다.
- 배치 행렬곱은 고객별 반복 계산을 한 번에 처리한다.
- Shape 오류는 행렬곱의 가운데 차원이 맞지 않을 때 발생한다.
- 전치행렬은 행과 열을 바꾸며, 행렬곱을 전치하면 곱의 순서도 반대로 바뀐다.
