# Reshape·Transpose·Broadcasting과 행렬곱 Shape 추론

> 학습일: 2026-08-07

## 1. 오늘 학습한 내용을 나만의 언어로 정리하기

### Shape를 바꾸는 연산

`reshape`, `transpose`, `squeeze`, `unsqueeze`는 Tensor의 Shape를 목적에 맞게 바꾸는 연산이다.

| 연산 | 역할 |
| --- | --- |
| `reshape` | 전체 원소 수를 유지하면서 Shape를 다시 구성한다. |
| `transpose` | 축의 순서를 교환한다. |
| `squeeze` | 크기가 1인 축을 제거한다. |
| `unsqueeze` | 원하는 위치에 크기가 1인 축을 추가한다. |

`reshape` 전후에는 전체 원소 수가 같아야 한다. 따라서 새 Shape의 각 축 크기를 모두 곱한 값이 원래 원소 수와 다르면 바꿀 수 없다.

### Broadcasting

Broadcasting은 Shape가 다른 두 배열을 연산할 때 필요한 축을 자동으로 맞추는 규칙이다. 두 Shape를 뒤쪽 축부터 비교하며 다음 조건 중 하나를 만족해야 한다.

```text
두 축의 크기가 같음
또는
둘 중 한 축의 크기가 1
```

조건을 만족하지 않는 축이 있으면 Broadcasting을 적용할 수 없다.

### 행렬곱의 Shape

2차원 행렬곱은 다음처럼 앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 한다.

```text
(m, n) @ (n, p) → (m, p)
```

안쪽 차원 `n`은 행렬곱이 가능한지를 결정하고, 결과에는 바깥쪽 차원 `m`, `p`가 남는다.

Batch가 포함된 행렬곱에서는 앞쪽 Batch 축을 유지하고 마지막 두 축을 행렬 Shape로 보아 같은 규칙을 적용한다.

## 2. 학습하며 겪었던 문제점과 해결 과정

### 질문: `reshape`에서 `-1`로 자동 계산되는 값은 자연수로 나와야 하는가?

`-1`은 전체 원소 수와 이미 지정한 축의 크기를 이용해 남은 축 하나의 크기를 자동으로 계산하라는 뜻이다.

```text
자동 계산할 축의 크기
= 전체 원소 수 ÷ 지정된 축 크기들의 곱
```

계산 결과는 축의 크기로 사용할 수 있는 정수로 정확히 나누어떨어져야 한다.

```text
원소 12개를 reshape(3, -1)
→ 12 ÷ 3 = 4
→ Shape (3, 4)

원소 12개를 reshape(5, -1)
→ 12 ÷ 5가 정수로 나누어떨어지지 않음
→ 변경 불가능
```

### 이해 수정: `transpose`와 전치

#### 처음 이해

`transpose`와 수학에서 배운 전치가 서로 다른 개념일 수 있다고 생각했다.

#### 해결 및 이해

`transpose`는 축의 순서를 교환하는 연산이다. 2차원 행렬에서는 두 축인 행과 열을 맞바꾸므로 수학에서 배운 전치와 같은 의미다.
