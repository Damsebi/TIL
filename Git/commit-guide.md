| 타입        |      의미      |                   예시                   |

| `feat`     | 새 기능         | `feat: add login button`               |
| `fix`      | 버그 수정       | `fix: resolve null pointer exception`  |
| `docs`     | 문서만 변경      | `docs: update README`                  |
| `refactor` | 코드 리팩터링    | `refactor: extract validation logic`   |
| `chore`    | 빌드/설정 변경   | `chore: update .gitignore`             |
| `test`     | 테스트 추가      | `test: add unit tests for auth module` |
