# Git 기본 명령어

> 학습일: 2026-08-03

## 1. `git clone`

```bash
git clone <원격 저장소 주소>
```

원격 저장소에 있는 파일과 Git 이력을 로컬 저장소로 가져옵니다.

## 2. `git status`

```bash
git status
```

현재 작업 디렉터리와 스테이징 영역의 상태를 확인합니다.

수정된 파일, 스테이징된 파일, 현재 브랜치 등의 정보를 확인할 수 있습니다.

## 3. `git add`

```bash
git add .
```

변경 사항을 스테이징 영역에 등록합니다.

`.`을 사용하면 현재 디렉터리 아래에 있는 모든 변경 사항이 스테이징됩니다.

특정 파일만 스테이징하려면 파일 이름을 지정합니다.

```bash
git add README.md
```

## 4. `git diff`

```bash
git diff
```

아직 스테이징하지 않은 변경 내용을 확인합니다.

커밋하기 전에 `git diff`로 변경 내용을 검토하는 습관을 들이는 것이 좋습니다.

스테이징한 변경 내용을 확인하려면 다음 명령어를 사용합니다.

```bash
git diff --staged
```

## 5. `git commit`

```bash
git commit -m "커밋 메시지"
```

스테이징된 변경 사항을 로컬 저장소에 하나의 커밋으로 기록합니다.

`-m`은 명령어에서 커밋 메시지를 직접 작성하기 위한 옵션이며, 따옴표 안의 문자열이 커밋 메시지가 됩니다.

예시:

```bash
git commit -m "docs: Git 명령어 정리"
```
