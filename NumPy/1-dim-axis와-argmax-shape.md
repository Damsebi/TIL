# NumPy·PyTorch의 Dim, Axis와 Argmax Shape

> 학습일: 2026-09-01

## 1. 오늘 학습한 내용을 나만의 언어로 정리하기

### Dim과 Axis는 차원의 번호

차원 번호는 앞쪽부터 `0, 1, 2, ...` 순서로 붙는다. Shape가 `(2, 3, 4)`인 3차원 Tensor를 예로 들면 다음과 같다.

| 차원 | 해당 차원의 크기 |
| --- | --- |
| `dim=0` | `2` |
| `dim=1` | `3` |
| `dim=2` | `4` |

`dim=0`은 가장 작은 차원이라는 뜻이 아니라 **첫 번째 차원에 붙은 번호**다. PyTorch에서는 주로 `dim`, NumPy에서는 같은 개념을 `axis`라고 표현한다.

### 마지막 두 차원을 행과 열로 읽기

`(2, 3, 4)`의 마지막 두 차원 `(3, 4)`를 행렬로 해석하면 3행 4열이고, 전체는 **3×4 행렬이 2개 있는 구조**로 볼 수 있다.

다만 Tensor의 마지막 두 차원이 항상 행과 열이라는 뜻은 아니다. 현재 데이터를 행렬처럼 다루는 상황에서 그렇게 해석하는 것이다.

### `argmax(dim=...)`의 비교 방향과 결과 Shape

`argmax(dim=n)`은 n번째 차원 방향에 놓인 값들을 비교하고, 가장 큰 값이 있던 Index를 반환한다.

Shape가 `(2, 3, 4)`일 때 `argmax(dim=0)`은 각 `(행, 열)` 위치마다 다음 두 값을 비교한다.

```text
tensor[0, 행, 열]
tensor[1, 행, 열]
```

기본값인 `keepdim=False`에서는 비교에 사용한 차원이 결과 Shape에서 제거된다.

| 연산 | 결과 Shape |
| --- | --- |
| `argmax(dim=0)` | `(3, 4)` |
| `argmax(dim=1)` | `(2, 4)` |
| `argmax(dim=2)` | `(2, 3)` |

따라서 다음 세 문장으로 연결해 이해했다.

```text
n번째 축을 따라 값들을 비교한다.
→ 가장 큰 값의 Index를 반환한다.
→ 기본 설정에서는 결과 Shape에서 n번째 축이 사라진다.
```

PyTorch에서 `keepdim=True`, NumPy에서 `keepdims=True`를 사용하면 해당 축을 제거하지 않고 크기 `1`인 차원으로 유지할 수 있다.

## 2. 학습하며 겪었던 문제점과 해결 과정

### 이해 수정: `dim=0`의 의미

#### 처음 이해

숫자 `0`이 가장 작은 차원을 가리키는 것처럼 생각했다.

#### 수정된 이해

Dim의 숫자는 차원의 크기나 중요도가 아니라 **앞에서부터 붙인 위치 번호**다. `argmax`에서는 이 번호를 보고 어느 방향의 값들을 비교할지 정한다.
