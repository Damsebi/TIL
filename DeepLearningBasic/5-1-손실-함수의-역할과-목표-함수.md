# 손실 함수의 역할과 목표 함수

> 학습일: 2026-08-24

## 핵심 정리

손실 함수는 Model의 Prediction과 Target을 비교해 얼마나 틀렸는지를 수치로 표현한다. Loss 계산만으로 Parameter가 바뀌는 것은 아니며, `backward()`가 Gradient를 계산하고 `optimizer.step()`이 실제 Weight와 Bias를 변경한다.

MSE는 오차를 제곱한 뒤 평균한다. 제곱은 양수와 음수 오차의 상쇄를 막고 큰 오차의 상대적인 영향을 키운다. 다만 절댓값이 1보다 작은 오차는 제곱하면 값 자체가 작아지므로, 모든 오차가 제곱 후 커진다고 이해하면 안 된다.

`reduction`은 여러 개별 Loss를 어떻게 집계할지 정한다. 평균 Loss는 전체적인 오차를 줄이는 기준이지 모든 Sample의 오차가 동시에 줄어든다는 보장은 아니다.

> Loss는 얼마나 틀렸는지를 나타내는 학습 목표이고, Gradient는 그 목표를 줄이기 위해 Parameter를 어느 방향으로 바꿔야 하는지를 나타낸다.

---

## 손실 함수가 필요한 이유

정답 여부만 확인하면 두 Prediction이 얼마나 다르게 틀렸는지 구분하기 어렵다.

```text
Target: 3.5억

Model A: 3.4억 → 0.1억 차이
Model B: 1.0억 → 2.5억 차이
```

두 Prediction 모두 정확한 정답은 아니지만 Model A가 Target에 훨씬 가깝다. 손실 함수는 이런 차이를 연속적인 숫자로 표현한다.

```text
Prediction과 Target 비교
→ Loss 계산
→ 얼마나 틀렸는지 수치화
```

앞 강의에서 학습 흐름을 전체적으로 다뤘으므로 이번에는 역할만 짧게 구분한다.

```text
Loss
→ 현재 Prediction이 얼마나 틀렸는지 평가

Gradient
→ 현재 위치에서 Parameter를 바꿀 때 Loss가 변하는 방향과 변화율

Optimizer
→ Gradient를 사용해 Weight와 Bias를 실제로 변경

Weight와 Bias
→ Model 내부에 저장되어 학습을 통해 바뀌는 Parameter
```

## Loss와 Objective의 범위

기초 학습에서는 Loss와 Objective를 비슷한 의미로 사용하기도 하지만, 엄밀히는 범위가 다를 수 있다.

```text
Loss
→ Prediction과 Target 사이의 예측 오차

Objective
→ 학습에서 최종적으로 최소화할 전체 식
```

예를 들어 예측 오차에 Regularization 항을 더하면 다음처럼 표현할 수 있다.

$$
\text{Objective}
=\text{Data Loss}
+\lambda\,\text{Regularization}
$$

이번 강의에서는 Objective의 확장보다 Data Loss인 MSE의 계산 구조에 집중했다.

---

## MSE의 계산 구조

MSE는 Mean Squared Error, 즉 평균 제곱 오차다.

$$
\mathrm{MSE}
=\frac{1}{N}\sum_{i=1}^{N}
(\hat{y}_i-y_i)^2
$$

- $N$: 비교하는 원소 수
- $\hat{y}_i$: Model의 Prediction
- $y_i$: Target

계산 순서는 다음과 같다.

```text
Prediction - Target
→ 오차 계산

오차²
→ 각 오차 제곱

제곱 오차의 평균
→ 하나의 MSE Loss
```

예를 들어 다음 Prediction과 Target을 비교한다.

```text
Prediction = [2.5, 3.0, 4.0]
Target     = [3.0, 2.0, 5.0]
```

```text
오차      = [-0.5, 1.0, -1.0]
제곱 오차 = [0.25, 1.0, 1.0]
```

$$
\mathrm{MSE}
=\frac{0.25+1+1}{3}
=0.75
$$

코드로 공식을 직접 조립하면 다음과 같다.

```python
manual_loss = ((pred - target) ** 2).mean()
```

여기서 직접 계산한다는 것은 `.mean()`까지 손으로 구현한다는 뜻이 아니라 `nn.MSELoss()`를 사용하지 않고 MSE의 연산 순서를 직접 코드로 구성했다는 뜻이다.

## MSE에서 오차를 제곱하는 의미

### 오차 방향은 어떻게 처리될까?

Target에서 같은 거리만큼 떨어졌다면 음수 오차와 양수 오차의 크기는 같다.

```text
Target = 3

Prediction = 2 → 오차 -1
Prediction = 4 → 오차 +1
```

오차를 그대로 더하면 서로 상쇄될 수 있다.

```text
-2 + 2 = 0
```

제곱하면 두 오차가 모두 Loss에 반영된다.

```text
(-2)² + 2² = 4 + 4
```

MSE의 Loss 값에서는 부호가 사라지지만, 미분한 Gradient에는 방향 정보가 남는다.

$$
L=(\hat{y}-y)^2
$$

$$
\frac{\partial L}{\partial \hat{y}}
=2(\hat{y}-y)
$$

```text
Prediction < Target
→ Gradient 음수
→ Prediction을 높이는 방향으로 수정

Prediction > Target
→ Gradient 양수
→ Prediction을 낮추는 방향으로 수정
```

```text
MSE Loss
→ 얼마나 틀렸는지

Gradient
→ 어느 방향으로 수정해야 하는지
```

### 제곱하면 모든 오차가 커질까?

처음에는 제곱이 모든 오차에 더 큰 벌점을 준다고 생각하기 쉬웠다. 하지만 절댓값이 1보다 작은 수는 제곱하면 값이 작아진다.

```text
|오차| < 1
→ 제곱하면 수치가 작아짐

|오차| > 1
→ 제곱하면 수치가 커짐
```

```text
0.5² = 0.25
0.2² = 0.04

2² = 4
3² = 9
```

중요한 점은 큰 오차가 작은 오차보다 상대적으로 훨씬 강하게 반영된다는 것이다.

```text
오차 0.5와 2의 크기 차이
→ 4배

제곱 오차 0.25와 4의 차이
→ 16배
```

따라서 MSE는 모든 오차의 숫자를 무조건 키우는 함수가 아니라 큰 오차의 상대적인 영향력을 키우는 손실 함수로 이해했다.

MSE는 제곱값을 평균하므로 항상 0 이상이며, 0에 가까울수록 Prediction이 Target에 가깝다. 다만 모든 종류의 Loss나 Objective가 반드시 0 이상이어야 하는 것은 아니다.

## Reduction과 Scalar Loss

`reduction`은 여러 개별 Loss를 더 적은 수의 값으로 줄여 정리하는 방식이다.

개별 제곱 오차가 다음과 같다고 하자.

```text
[0.25, 1.0, 1.0]
```

| Reduction | 결과 | 의미 |
| --- | --- | --- |
| `none` | `[0.25, 1.0, 1.0]` | 개별 Loss 유지 |
| `mean` | `0.75` | 평균을 계산해 하나로 집계 |
| `sum` | `2.25` | 합계를 계산해 하나로 집계 |

```python
loss_none = nn.MSELoss(reduction="none")(pred, target)
loss_mean = nn.MSELoss(reduction="mean")(pred, target)
loss_sum = nn.MSELoss(reduction="sum")(pred, target)
```

일반적으로 Scalar Loss 하나를 사용하는 이유는 여러 오차를 학습에서 최소화할 하나의 목표로 정리하기 위해서다.

```text
여러 개별 오차
→ Reduction
→ Scalar Loss
→ backward()
→ 각 Parameter의 Gradient
```

Reduction은 목표를 하나로 집계하고, Gradient는 그 목표를 줄이는 방향을 계산한다.

## 평균 Loss를 해석할 때의 주의점

처음에는 평균 Loss가 줄면 모든 Sample의 오차가 동시에 줄어든다고 생각했다. 하지만 평균이 감소해도 일부 Sample의 오차는 커질 수 있다.

```text
업데이트 전
A = 1, B = 4, C = 4
평균 = 3

업데이트 후
A = 2, B = 2, C = 2
평균 = 2
```

전체 평균은 줄었지만 A의 오차는 `1 → 2`로 증가했다.

> 평균 Loss를 줄인다는 것은 모든 개별 오차를 반드시 동시에 줄이는 것이 아니라 전체적으로 평균적인 오차를 줄인다는 뜻이다.

또한 평균이 실제 문제의 중요도를 항상 올바르게 반영하는 것도 아니다.

```text
정상 Sample 990개
불량 Sample 10개
```

모든 Sample을 정상으로 예측하면 Accuracy가 99%여도 불량 검출이라는 목적에는 실패한다. 특정 Class나 오류의 비용이 더 중요하다면 Weighting, Sampling, 다른 Loss 또는 평가 지표를 검토해야 한다.

## `nn.MSELoss()`를 올바르게 호출하기

처음에는 다음처럼 Class 생성자에 Prediction과 Target을 전달하려고 했다.

```python
loss = nn.MSELoss(pred, target)
```

`nn.MSELoss`는 Loss 값을 바로 계산하는 일반 함수가 아니라 손실 함수 Module을 만드는 Class다. 먼저 객체를 생성한 뒤 그 객체를 호출해야 한다.

```python
criterion = nn.MSELoss()
loss = criterion(pred, target)
```

한 줄로도 쓸 수 있다.

```python
loss = nn.MSELoss()(pred, target)
```

```text
nn.MSELoss()
→ 손실 함수 객체 생성

criterion(pred, target)
→ 생성한 객체에 Prediction과 Target 전달
→ Loss 계산
```

반복해서 사용할 때는 매번 새 객체를 만들기보다 반복문 밖에서 한 번 생성하는 편이 자연스럽다.

## 손실 함수에 맞는 출력과 Target

Prediction과 Target의 Shape·Dtype은 사용하는 손실 함수의 규격에 맞아야 한다.

```python
binary_logits = torch.tensor([[0.2], [-1.0], [1.5]])
binary_target = torch.tensor([[1.0], [0.0], [1.0]])

multi_logits = torch.tensor([
    [2.0, 0.3, -0.5],
    [0.1, 1.4, 0.2]
])
multi_target = torch.tensor([0, 1])

bce_loss = nn.BCEWithLogitsLoss()(
    binary_logits,
    binary_target
)

ce_loss = nn.CrossEntropyLoss()(
    multi_logits,
    multi_target
)
```

| 손실 함수 | Model 출력 | Target |
| --- | --- | --- |
| `BCEWithLogitsLoss` | Raw Logit, Shape `[N, 1]` | 실수형 0 또는 1, Shape `[N, 1]` |
| `CrossEntropyLoss` | Class별 Raw Logit, Shape `[N, C]` | Class Index, `torch.long`, Shape `[N]` |

두 손실 함수 모두 위와 같은 일반적인 사용에서는 Raw Logit을 직접 받으므로 Model 출력에 `sigmoid`나 `softmax`를 먼저 적용하지 않는다.

`CrossEntropyLoss`의 Target이 `long`이어도 계산 결과인 Loss는 Class 번호가 아니라 연속적인 오차 크기이므로 실수형 Scalar Tensor다.

```text
CrossEntropyLoss Target
→ Class Index
→ torch.long

CrossEntropyLoss 결과
→ 오차의 크기
→ Float Tensor
```

## 다시 볼 때 핵심

손실 함수는 Prediction과 Target을 비교해 얼마나 틀렸는지 수치화한다. Loss 자체가 Parameter를 바꾸지는 않으며, Gradient 계산과 Optimizer Update가 뒤따라야 한다.

MSE는 `오차 → 제곱 → 평균` 순서로 계산한다. 제곱은 오차의 상쇄를 막고 큰 오차의 상대적인 영향력을 키우지만, 절댓값이 1보다 작은 오차의 수치까지 무조건 키우는 것은 아니다.

MSE Loss에는 부호가 없지만 그 미분값인 Gradient에는 수정 방향이 나타난다.

Reduction은 여러 Loss를 `none`, `mean`, `sum` 방식으로 처리한다. 평균 Loss가 감소해도 모든 Sample의 오차가 동시에 감소하는 것은 아니며, Loss가 실제 문제의 중요도를 반영하는지도 확인해야 한다.

`nn.MSELoss()`로 손실 함수 객체를 만든 뒤 `criterion(pred, target)`으로 호출한다.

손실 함수마다 요구하는 출력과 Target Shape·Dtype이 다르다. `BCEWithLogitsLoss`와 `CrossEntropyLoss`에는 일반적으로 `sigmoid`나 `softmax`를 적용하기 전 Raw Logit을 전달한다.
