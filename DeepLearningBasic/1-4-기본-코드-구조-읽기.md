# 기본 코드 구조 읽기

> 학습일: 2026-08-19

## 핵심 정리

PyTorch 코드를 처음부터 한 줄씩 완벽히 해석하려고 하면 전체 흐름을 놓치기 쉽다. 먼저 Import, 데이터 준비, 모델, Loss, Optimizer, Train, Validation, 기록, 저장처럼 역할별 블록을 구분해서 읽는 것이 중요하다.

모델을 정의하는 코드와 실제 예측을 실행하는 코드는 다르다. 모델 구조는 `nn.Sequential(...)`에서 정하고, 실제 예측값은 `model(batch_x)`를 호출할 때 만들어진다.

Train에서는 예측하고 채점한 뒤 파라미터를 수정한다. Validation에서는 예측하고 채점하지만 파라미터를 수정하지 않는다.

> 코드를 전부 외우기보다 “데이터를 준비하는 부분인가, 예측하는 부분인가, 채점하는 부분인가, 수정하는 부분인가, 기록하거나 저장하는 부분인가?”를 먼저 구분하면 전체 구조를 읽기 쉬워진다.

---

## PyTorch 코드의 큰 구조

PyTorch 학습 코드는 보통 다음 역할의 블록으로 나눠 읽을 수 있다.

```text
import
→ config / hyperparameter
→ dataset / dataloader
→ model
→ loss
→ optimizer
→ train loop
→ validation loop
→ metric / logging
→ checkpoint
```

현재 목표는 모든 문법과 내부 원리를 한 번에 암기하는 것이 아니다. 반복해서 코드를 보며 각 블록이 어떤 역할인지 눈에 익히는 것이다.

---

## Import 영역

### 처음 보는 이름을 전부 외워야 할까?

`torch`, `nn`, `DataLoader`, `TensorDataset`을 처음 봤을 때 바로 읽히지 않아 모두 암기해야 하는지 궁금했다.

처음부터 전부 외우기보다 자주 등장하는 핵심 역할을 먼저 연결한다.

```python
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset
```

```text
torch
= PyTorch의 핵심 기능

nn
= 신경망 모델과 레이어 관련 기능

TensorDataset
= Tensor들을 Dataset 형태로 묶음

DataLoader
= Dataset에서 데이터를 Batch 단위로 꺼냄
```

`nn`이 보이면 신경망 모델이나 레이어를 다루는 부분이라고 먼저 추측할 수 있다.

## 데이터 준비 코드 읽기

```python
dataset = TensorDataset(X, y)

train_loader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True
)
```

코드를 읽을 때는 `TensorDataset`에서 입력과 정답을 묶고, `DataLoader`에서 Batch Size와 Shuffle 설정을 정하는 블록이라고 구분한다.

---

## 모델 정의와 실제 예측

### 모델을 정의하는 부분에서 바로 예측값이 만들어질까?

아니다.

다음 코드는 어떤 구조로 예측할지를 정의한다.

```python
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Linear(16, 1)
)
```

실제 예측은 모델에 Batch를 넣어 호출할 때 일어난다.

```python
preds = model(batch_x)
```

```text
model = 예측 구조를 정의한 객체

model(batch_x)
= 현재 파라미터로 실제 예측값을 계산
```

---

## 모델의 Shape 흐름 읽기

레이어의 자세한 원리를 다시 설명하기보다 입력과 출력 Shape가 어떻게 이어지는지 확인한다.

```text
[Batch, 4]
→ Linear(4, 16)
→ [Batch, 16]
→ ReLU
→ [Batch, 16]
→ Linear(16, 1)
→ [Batch, 1]
```

## Loss와 Optimizer 코드 읽기

```python
loss_fn = nn.MSELoss()

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.05
)
```

```text
loss_fn
→ 예측을 채점하는 기준

optimizer
→ 파라미터를 수정하는 방법과 Learning Rate 설정
```

---

## Train과 Validation Loop 읽기

Train Loop에서는 다음 다섯 줄을 하나의 반복 흐름으로 읽는다.

```python
optimizer.zero_grad()
preds = model(batch_x)
loss = loss_fn(preds, batch_y)
loss.backward()
optimizer.step()
```

```text
Gradient 초기화
→ 예측
→ Loss 계산
→ Gradient 계산
→ 파라미터 수정
```

Validation 코드에서는 예측과 채점은 있지만 Backward와 Optimizer Step은 없는지 확인한다.

```python
with torch.no_grad():
    preds = model(batch_x)
    val_loss = loss_fn(preds, batch_y)
```

## Metric, Matrix, History

### Metric은 Matrix와 같은 뜻일까?

처음에는 발음이 비슷한 Metric과 Matrix를 같은 개념으로 생각했다.

둘은 서로 다른 단어다.

```text
metric
= 평가 지표

matrix
= 행렬
```

Metric의 예로 Accuracy, Precision, Recall, F1 Score가 있다.

학습 과정에서 Epoch별 성적을 기록하는 변수는 예제에서 `history`였다.

```python
history.append({
    "epoch": epoch,
    "train_loss": train_loss,
    "valid_loss": valid_loss
})
```

```text
metric
= 어떤 기준으로 성능을 평가할지

history
= Epoch별 성적을 기록하는 곳
```

`confusion matrix`처럼 실제로 Matrix라는 이름이 붙은 것은 행렬이다.

## Checkpoint

다음 코드는 학습한 모델의 상태를 파일로 저장한다.

```python
torch.save(model.state_dict(), "model.pt")
```

`state_dict()`에는 모델이 학습한 Weight와 Bias 같은 파라미터 상태가 들어 있다.

현재 단계에서는 다음처럼 이해한다.

> Checkpoint는 학습한 모델의 상태를 저장하는 부분이다.

## 코드를 다시 볼 때의 순서

처음부터 세부 문법을 모두 해석하려고 하기보다 다음 질문을 순서대로 던진다.

```text
1. 어떤 라이브러리를 가져오는가?
2. 데이터와 정답을 어떻게 묶는가?
3. Batch를 어떻게 꺼내는가?
4. 모델의 입력과 출력 Shape는 무엇인가?
5. 어떤 Loss로 채점하는가?
6. 어떤 Optimizer와 Learning Rate로 수정하는가?
7. Train Loop에서 예측·채점·수정이 어디서 일어나는가?
8. Validation에서는 무엇을 빼고 평가하는가?
9. 성적은 어디에 기록하는가?
10. 모델은 어디에서 저장하는가?
```

전체 흐름은 다음과 같다.

```text
Tensor 데이터
→ TensorDataset으로 입력과 정답을 묶음
→ DataLoader가 Batch로 가져옴
→ Model이 예측
→ Loss가 채점
→ Backward가 수정 방향 계산
→ Optimizer가 파라미터 수정
→ History에 성적 기록
→ Validation으로 성능 확인
→ Checkpoint로 모델 상태 저장
```
