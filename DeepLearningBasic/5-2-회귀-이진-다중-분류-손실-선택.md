# 회귀·이진·다중 분류 손실 선택

> 학습일: 2026-08-24

## 1. 오늘 학습한 내용을 나만의 언어로 정리하기

### 무엇을 맞히는지부터 보고 Loss를 고른다

처음에는 회귀는 MSE, 이진 분류는 BCE, 다중 분류는 CE처럼 이름을 연결했다. 이제는 **샘플 하나에서 무엇을 맞힐지 → 모델이 어떤 값을 몇 개 낼지 → 정답을 어떤 형태로 줄지 → Loss** 순서로 함께 본다.

이번 실습의 기본 선택은 다음과 같다. `B`는 샘플 수, `C`는 클래스 수, `L`은 독립적으로 판정할 레이블 수다.

| 문제 | 모델 출력 Shape | Target Shape | Target 의미·Dtype | Loss |
| --- | --- | --- | --- | --- |
| 회귀: 실제 숫자 하나 맞히기 | `(B, 1)` | `(B, 1)` | 실제 수치, `float` | `MSELoss` |
| 이진 분류: Yes/No 하나 판정하기 | `(B, 1)` | `(B, 1)` | 0/1 목표값, `float` | `BCEWithLogitsLoss` |
| 다중 레이블: Yes/No 여러 개 판정하기 | `(B, L)` | `(B, L)` | 레이블별 0/1 목표값, `float` | `BCEWithLogitsLoss` |
| 다중 분류: 여러 후보 중 하나 고르기 | `(B, C)` | `(B,)` | 정답 클래스 번호, `long` | `CrossEntropyLoss` |

회귀 출력은 예측하려는 수치이고, 표의 분류 출력은 확률로 바꾸기 전의 Logits다. `BCEWithLogitsLoss`와 `CrossEntropyLoss`에는 Sigmoid·Softmax를 미리 적용하지 않는다.

문제 A·B는 `B=8`, 문제 C는 `B=8, C=5`로 읽었다. BCE에서는 출력과 Target을 모두 `(8,)`로 맞춰도 된다. **무조건 2차원으로 만드는 것이 아니라 Loss가 요구하는 대응 관계를 맞추는 것**이다.

## 2. 학습하며 겪었던 문제점과 해결 과정

### 이해 수정: 다중 분류와 다중 레이블

#### 처음 이해

다중 분류는 여러 개가 동시에 정답일 수 있고, 이진 분류는 여러 후보 중 하나를 고르는 문제라고 생각했다.

#### 수정된 이해

- 이진 분류: 두 종류 중 하나가 정답이다.
- 다중 분류: 여러 클래스 중 하나가 정답이다.
- 다중 레이블: 여러 레이블이 동시에 정답일 수 있다.

예를 들어 `화염인가?`, `비행인가?`, `보스인가?`는 한 샘플에서 동시에 Yes일 수 있다. **이진 질문 하나를 여러 개 나란히 놓은 것**이므로 레이블마다 Logit 하나를 내고 BCE 방식으로 다룰 수 있다.

---

### 질문: 다중 분류는 무조건 정답이 하나인가?

여기서 정답 하나는 **샘플 하나 기준**이다. 사진 여러 장 중 고양이 사진이 여러 장 있어도, 각 사진에 정답 클래스가 하나씩 붙으면 다중 분류다.

반면 사진 한 장에서 고양이와 강아지 등 여러 레이블을 동시에 맞히도록 정했다면 다중 레이블로 볼 수 있다. 데이터 전체에서 정답이 하나라는 뜻은 아니다.

---

### 질문: 이진 분류는 왜 Logit 하나이고 CE는 여러 개인가? BCE는 항상 하나인가?

BCE는 Binary Cross Entropy다. 이번에 쓰는 `BCEWithLogitsLoss`에서는 **출력 하나가 독립적인 Yes/No 질문 하나**에 대응한다.

`고양이인가?`라는 질문 하나라면 Logit 하나로 충분하다. 고양이일 확률이 `p`이면 아닐 확률은 `1-p`이기 때문이다. 질문이 3개인 다중 레이블이라면 Logit도 3개이므로, BCE가 출력 하나만 받는다는 뜻은 아니다.

반면 CE로 후보 네 개 중 하나를 고르면 `[고양이 점수, 강아지 점수, 호랑이 점수, 사자 점수]`처럼 후보마다 점수가 필요하다. **출력 개수는 Loss 이름만 보고 외우기보다 질문을 어떻게 구성했는지와 함께 본다.**

---

### 질문: 다중 분류도 후보마다 이진 질문으로 만들 수 있지 않은가?

가능하다. 다만 `고양이인가?`, `강아지인가?`를 BCE로 각각 채점하면 두 질문 모두 높은 확률을 받을 수 있다. BCE 자체가 반드시 하나만 선택하게 만드는 것은 아니다.

반대로 **후보들이 서로 경쟁해서 하나를 고르는 문제라면 CE가 기본 선택**이다. 여러 Yes/No 질문으로 쪼개는 것과 여러 후보 중 하나를 고르는 것은 같은 구성이 아니다.

---

### 질문: 다중 분류에서 두 클래스의 점수가 같으면 어떻게 되는가?

정답이 하나라고 모델의 최고 점수도 반드시 하나만 나오는 것은 아니다. 점수가 같거나 비슷할 수 있고, `argmax()`는 최종적으로 인덱스 하나를 고른다.

**정답이 하나인 것과 모델이 확실하게 맞힌 것은 별개**다. 최종 예측의 정오와 Loss는 Validation·Test에서 평가한다.

---

### 질문: Logit·Sigmoid·Softmax도 오차를 구하는 과정인가?

처음에는 Logit 자체도 `0~1` 범위라고 혼동했다. Logit은 범위 제한이 없는 원래 점수이고, Sigmoid·Softmax가 그 점수를 확률로 바꾼다.

**점수를 만드는 것, 확률로 바꾸는 것, 정답과 비교해 채점하는 것은 구분한다.** Sigmoid·Softmax 자체는 Target과 비교하는 함수가 아니다. 이번 Loss 함수들은 Raw Logits를 받아 필요한 변환과 채점을 처리한다.

Loss 계산 후 `backward()`는 Gradient를 계산하고, `optimizer.step()`이 Parameter를 실제 수정한다. `backward()`가 직접 Weight·Bias를 바꾸는 것은 아니다.

---

### 이해 수정: CE Target의 Shape와 `float`·`long`

#### 처음 이해

CE의 Target도 Sigmoid·Softmax 결과처럼 `0~1`일 것이라고 생각했다. Target이 `(B,)`인 이유도 모델 출력이 `(B, 1)`이 아니기 때문인지 헷갈렸다.

BCE는 값을 비교하니까 `float`라고 이해했지만, CE는 왜 `long`인지 연결되지 않았다.

#### 수정된 이해

**MSE·BCE의 Target은 목표 수치이고, 이번 CE의 Target은 정답 위치를 가리키는 번호**다. MSE는 실제 연속 수치, BCE는 `0~1`의 실수형 목표값을 받는다. 기본 0/1 Label도 BCE에는 `0.0`, `1.0`처럼 전달한다.

CE에서 `0=고양이, 1=강아지, 2=호랑이, 3=사자`라면 `target=2`는 예측값을 숫자 2에 가깝게 만들라는 뜻이 아니라 **호랑이가 정답이라는 뜻**이다.

```python
import torch

logits = torch.randn(8, 5)
target = torch.tensor([0, 1, 2, 3, 4, 0, 1, 2], dtype=torch.long)
```

문제 C에서는 샘플마다 점수 5개가 필요하지만, 정답은 그중 몇 번인지 번호 하나만 있으면 된다.

```text
Logits (8, 5) → 샘플 8개 × 후보 점수 5개
Target (8,)   → 샘플 8개의 정답 번호를 하나씩 저장
```

Target을 Class 인덱스로 전달하므로 `long`을 쓴다. **Target Shape를 출력 모양에 억지로 맞추는 것이 아니라, 정답을 어떻게 표현하는지에서 읽어야 한다.**

---

### 이해 수정: `torch.randn(8, 1)`의 숫자

처음에는 `0~8` 사이에서 값을 뽑는 것으로 생각했다. 여기서 `8, 1`은 값의 범위가 아니라 **만들 Tensor의 Shape**다.

문제 A에서는 샘플 8개에 예측값과 정답값이 하나씩 있는 구조다.

```python
pred = torch.randn(8, 1)
target = torch.randn(8, 1)
```

`randn()`은 평균 0, 표준편차 1인 정규분포에서 실수를 만든다. 이 두 Tensor는 대응하는 수치를 비교할 회귀 연습용 값이므로 같은 Shape의 Float Tensor로 두고 MSE를 선택했다.

---

### 질문: 샘플값이 무엇인가?

처음에는 `0.1, 1.2, 1.5` 같은 숫자 각각을 샘플 하나로 생각했고, 샘플과 클래스도 혼동했다.

샘플은 **입력 데이터 하나 전체**다. 동물 한 마리의 데이터라면 `[귀 길이, 몸무게, 털 길이, 키] = [3.2, 5.1, 1.4, 27.0]`처럼 샘플 하나에 여러 Feature가 들어갈 수 있다. 이미지에서는 사진 한 장이 샘플이고 픽셀 정보가 입력이다.

사진 5장과 정답 후보 4종이면 `B=5`, `C=4`이므로 Logits는 `(5, 4)`다. 사진이 많아서 다중 분류인 것이 아니라 **사진 하나에 대해 고를 정답 후보가 여러 종류라서 다중 분류**다.

---

### 질문: 여러 Feature를 합쳐 각 정답 후보와 비교하는가?

입력 숫자들을 정답 후보와 직접 비교하는 것은 아니다. 모델이 Weight·Bias를 적용해 각 후보의 점수를 계산한다.

마지막 Linear에서는 들어온 Feature들에 클래스마다 서로 다른 Weight·Bias를 적용해 `고양이 Logit`, `강아지 Logit` 등을 만든다. 이 Feature는 입력에서 바로 온 값일 수도 있고 앞 층이 만든 표현일 수도 있다.

이번에는 **샘플 안의 여러 Feature를 이용해 클래스별 점수를 만든다**는 관계로 이해했다.
