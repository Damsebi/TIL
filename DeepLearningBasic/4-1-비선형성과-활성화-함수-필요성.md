## 2. 오늘 학습한 내용을 나만의 언어로 정리하기

### Linear Layer만 쌓을 때의 한계

`nn.Linear`는 이름은 Linear지만 실제 계산은 Bias가 포함된 `Wx + b` 형태의 아핀 변환이다. 활성화 함수 없이 Linear Layer를 여러 개 연결하면 전체 계산을 다시 하나의 아핀 변환으로 합칠 수 있다.

$$
W_2(W_1x+b_1)+b_2
=(W_2W_1)x+(W_2b_1+b_2)
$$

따라서 Layer가 여러 개 있어도 활성화 함수가 없다면 선형적인 결정 경계만 표현할 수 있다. XOR처럼 직선 하나로 분리할 수 없는 패턴을 표현하는 데 한계가 생긴다.

### ReLU가 추가하는 비선형성

ReLU는 음수 값을 0으로 바꾸고 양수 값은 그대로 통과시킨다.

$$
\mathrm{ReLU}(x)=\max(0,x)
$$

ReLU의 핵심은 출력값의 종류를 늘리는 것이 아니라 중간 표현에 꺾임을 만들어 Model에 비선형성을 추가하는 것이다.

```text
Linear → Linear
→ 하나의 Linear 형태로 합칠 수 있음

Linear → ReLU → Linear
→ ReLU의 꺾임 때문에 하나의 Linear로 합칠 수 없음
```

ReLU는 일반적으로 Tensor의 Shape를 바꾸지 않고 값만 비선형적으로 변환한다. 여러 비선형 변환을 조합하면 하나의 직선보다 복잡한 결정 경계를 표현할 수 있다.

### XOR와 비선형 Feature

XOR는 원래 입력 공간에서 직선 하나로 분리할 수 없다. 하지만 `x_1x_2` 같은 비선형 Feature를 직접 추가하면 입력 표현을 확장할 수 있다.

```text
[x1, x2]
→ [x1, x2, x1*x2]
```

이는 사람이 XOR에 적합한 비선형 Feature를 직접 설계한 예다. 신경망에서는 활성화 함수를 사용해 입력을 비선형적인 중간 표현으로 바꾸고, 복잡한 패턴을 학습할 수 있게 한다.
